# 🟨 Codexeron JavaScript SDK

Official JavaScript SDK for the Codexeron Marketplace.

Build modern web applications with the official Codexeron API.

---

## ✨ Features

- Secure Authentication
- Product Management
- Order Management
- User Management
- License Verification
- Search API
- Webhooks

---

## 🌍 Why Codexeron?

Codexeron is a developer-first marketplace designed for software creators.

Whether you build PHP scripts, SaaS platforms, AI tools, APIs or mobile applications, Codexeron provides a global marketplace to sell your digital products.
